# Notes

This folder holds knowledge, ideas, and long-form thinking.

## How to Use

Create notes when you want to preserve:
- learnings
- insights
- frameworks
- personal takeaways
- references that deserve context

## Template

Use [knowledge-template.md](./knowledge-template.md) as the standard format.

## Rules

- Prefer useful, clear writing over perfection
- Keep notes connected to context
- Link back to projects or areas when relevant
