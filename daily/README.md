# Daily Notes

This folder is for daily logging, reflections, and short captures.

## Purpose

Use these notes to:
- remember what happened
- track progress
- capture ideas while they are fresh
- support regular reflection

## Recommended Pattern

Each daily note should include:
- what happened
- what I learned
- what I am doing next
- any blockers or unresolved thoughts
